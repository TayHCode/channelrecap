# Roadmap

Later versions may add voice analysis from audio: pace over time, pauses and energy.
Text filler counts do not measure those audio features.

Frame search is planned for a later version: find a moment by describing the picture.
More languages for the topic, filler and deferral hint lists are also planned.
There are no dates or promises of a particular release.

Version 0.1 has no hosted transcription, model API calls, speaker separation, frame
search or voice analysis. Optional reference site captions are already supported. Package-index publication is outside
this build. Channel, playlist and search crawling are not planned. One row stays one
video supplied by its creator.
